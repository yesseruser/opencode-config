# Global Rules

## Waiting

To wait for a certain time, run `sleep` with the desired time.

## Changes

Adhere to `CONTRIBUTING.md` and `AGENTS.md` (or similar files) when they exist in the project root.

Load the relevant skill for the detail:

- `git-commit` — granular commits, commit message style, `Co-authored-by:` trailer, moving changes between branches
- `github-pr` — GitHub interaction with `gh`, branching vs committing to main, pushing, opening and merging PRs
- `coderabbit` — handling CodeRabbit review comments, rate limits, and review status
